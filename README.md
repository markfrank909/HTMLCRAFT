HTMLCRAFT 1.7_P1.1 - Changelog
Released: 2026-10-05

🎨 New Content
RU/EN language toggle - button in the top-left corner of the main menu. Switches every text in the game (menus, blocks, tools, inventory, chat, map, multiplayer, death and loading screens). Your choice is saved between sessions.

"How to play" window - button with a ? next to the language toggle. Opens a full controls guide. Close it with the X button in the top-right corner, the button at the bottom, Esc, or by clicking outside.

GitHub link - added at the bottom of the main menu, opens https://github.com/markfrank909/HTMLCRAFT in a new tab.

Hide interface (PC) - press H to hide the entire HUD (info panel, hotbar, health bar, crosshair, chat, water overlay). Press again to bring it back.

🔧 Changes
Version is now 1.7_P1.1 - visible in the main menu, the info panel, and the multiplayer window.

Multiplayer is no longer compatible with other versions - only 1.7_P1.1 players can connect to each other. Older (1.7_P1 and below) and newer builds are rejected with an "Incompatible version" message. This prevents desync, missing blocks, and crashes when mixing versions.

Drop slot moved - the 🗑 "Drop item" slot now sits under the crafting grid in the inventory, instead of under the hotbar. On phones, it now fits on screen.

Map controls fixed - the arrow buttons now form a proper cross (▲ over ◀ ▼ ▶, with − ⊙ + below), instead of being misaligned.

Full interface translation - previously the game only had Russian text. Now every label, button, tooltip, and status message has an English version.
